# Trading Card Studio

Turn any photo into a professionally designed trading card in seconds.

Upload a photo, pick a style (Aurora, Ember, Noir, Retro Arcade, or Garden), customize colors and text, then download a crisp PNG — or share it from your device.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- `html-to-image` for 2× PNG export
